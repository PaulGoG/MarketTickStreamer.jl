API reference: acquisition and storage

The public surface, grouped by pipeline stage. Each group is generated from one source file, so everything carrying a docstring appears here. The provider interface and the adapters are on the providers page; the analysis side — data quality, activity clocks, replay, corpus access and the diagnostic figures — on the analysis page.

Names with a leading underscore are internal. They are documented for the reader of the code and are not covered by the versioning policy of the README.

MarketTickStreamer — Module
MarketTickStreamer

Provider-agnostic tick-by-tick market data acquisition for scientific time series research: live WebSocket streaming, historical REST backfill, append-only raw persistence, compaction to analysis-ready files, and paced replay of recorded sessions.

Everything is driven by a TOML configuration (config/config.toml in a clone); credentials come from the environment file it names. Entry points: run_stream, run_backfill, run_import, replay_source, follow_source, compact_raw, read_processed.

Plotting is optional. The diagnostic figures (session_figure, overview_figure and their save_* drivers) are implemented by a package extension that loads with CairoMakie, and the terminal plots of monitor_raw by one that loads with UnicodePlots; neither is a dependency of the package.

Errors

An invalid argument or configuration value throws ArgumentError. Every other refusal or failure of the package throws one of the types below, so a caller can tell a full disk from a corrupt vendor file without reading the message.

MarketTickStreamer.CredentialError — Type
CredentialError(names, msg)

Credentials the provider declares (ProviderSpec.credential_keys) are absent from both the environment file and the process environment; names lists the missing variables.

source
MarketTickStreamer.FatalStreamError — Type
FatalStreamError(msg)

A stream error that must not trigger reconnection (bad credentials, connection-limit exceeded, invalid subscription). Aborts the session.

source
MarketTickStreamer.IntegrityError — Type
IntegrityError(source, msg)

Data failed verification (checksum, announced size) or does not have the structure its format specifies (a truncated message, a malformed capture block, a row filed under the wrong day). source names the file. A download that failed verification has been discarded; a malformed file is left as it is.

source
MarketTickStreamer.MarketTickStreamerError — Type
MarketTickStreamerError <: Exception

Supertype of the exceptions thrown when an operation is refused or fails for a reason outside its arguments. Invalid arguments and configuration values throw ArgumentError; HTTP statuses and transport failures that outlast the retry policy (RestPolicy) propagate as HTTP.jl's own exceptions.

TypeThrown when
ResourceErrorfree disk, scratch space, heap or memory is below what the operation needs
IntegrityErrordata fails verification or lacks the structure its format specifies
VendorErrora vendor's service does not deliver what it lists or was asked for
SessionErrorthe data tree is locked by another session, or a followed session stalls
CredentialErrorcredentials the provider needs are missing
FatalStreamErrorthe venue ends a live stream for a reason a reconnect cannot fix

Every subtype has a field msg, the account showerror prints, beside the fields a handler branches on.

source
MarketTickStreamer.ResourceError — Type
ResourceError(resource, msg)

A resource is short of what the operation needs. resource is :disk (free space on the data tree below limits.min_free_disk_gb), :scratch (no room for a spill compaction's scratch copy), :heap (live heap above limits.max_live_heap_mb) or :memory (a read that would exceed its share of free memory).

source
MarketTickStreamer.SessionError — Type
SessionError(path, msg)

The session lifecycle refused or ended an operation: another live session holds the data tree's lock (path is the lock file), or a followed session stopped growing while its sidecar still reads running (path is the sidecar).

source
MarketTickStreamer.VendorError — Type
VendorError(source, msg)

A vendor's service did not deliver what it lists or what was asked of it: no file listed for the date, a listed file missing, a Range request answered from the wrong offset, a download that stopped making progress. source is the URL. Nothing was written in its place; a later attempt may succeed.

MarketTickStreamer._resolve_config_date — Method
_resolve_config_date(spec, key, reference) -> Date

Resolve a configured calendar date. Accepts an ISO date ("2026-08-12") or a sentinel relative to reference: "today", or "today-<N>d" with N a non-negative integer number of calendar days. MarketTickStreamer.load_config — Function
load_config(path = DEFAULT_CONFIG) -> Config

Read and validate the TOML configuration. Relative storage.data_dir, logging.log_dir and credentials.env_file are resolved against the directory of path. Every key is checked for type and documented bounds, and unknown tables or keys are rejected, so a misspelt key cannot fall back to its default unnoticed. Throws ArgumentError naming the offending key.

The no-argument form reads the configuration shipped with the repository and suits a clone of it. In an installed copy of the package it throws an ArgumentError: there DEFAULT_CONFIG is a read-only template to copy into a project of your own.

Schema and timestamps

Timestamps are Int64 nanoseconds since the UNIX epoch everywhere, which holds the full range of exchange precision without rounding.

MarketTickStreamer.Bar — Type
Bar

One normalized aggregate bar: time_ns is the opening instant and close_ns the closing one, both in nanoseconds since the Unix epoch on the exchange clock, so a bar and the prints inside it share a time origin.

For an activity bar (tick_bars, volume_bars, dollar_bars) time_ns is the timestamp of its first print and close_ns that of the print that completed it. The duration close_ns - time_ns is then a random variable — the time the market needed to transact a fixed amount of activity — and is the observable a waiting-time study reads off an activity clock. For a venue-computed bar close_ns is the end of the venue's aggregation window.

Like Quote, bars are parsed but not subscribed to by default. They are a convenience the venue computes; anything a bar reports can be derived from the prints this package records, and the derivation is reproducible whereas the venue's aggregation rules are not fully observable.

source
MarketTickStreamer.Quote — Type
Quote

One normalized top-of-book quote: the best bid and offer as a venue reported them, with both clocks kept as for Trade — time_ns from the exchange, recv_ns from local receipt.

Quotes are parsed but not subscribed to by default, and not persisted. A quote stream carries an order of magnitude more messages than the trade stream, so persisting it is a storage decision, not a parsing one; reach them through the on_quote callback of live_source.

Sizes are round lots as the tape reports them, not shares.

source
MarketTickStreamer.Trade — Type
Trade

A single normalized trade (tick).

Fields

  • symbol : ticker symbol
  • time_ns : exchange/participant timestamp, ns since UNIX epoch (UTC)
  • recv_ns : local wall-clock receive timestamp, ns since UNIX epoch (UTC). The time_ns → recv_ns gap measures end-to-end latency and is 0 for records that never crossed the wire (e.g. backfilled).
  • price : trade price
  • size : trade size (Float64 to accommodate fractional shares/crypto)
  • exchange : exchange code (provider-specific, e.g. "V" = IEX)
  • conditions : trade condition codes (provider-specific)
  • tape : tape identifier ("A"/"B"/"C" for US equities, "SPOT" for Binance; may be empty)
  • id : provider trade id (0 when absent)

Persistence and compaction

MarketTickStreamer.SPILL_HEADROOM — Constant
SPILL_HEADROOM

Default multiple of the input size that the spill filesystem must have free before compact_raw will stream to it (spill_headroom).

The spill pass trades memory for scratch space, writing every input line back out once. tempdir() is the wrong home for that: on systemd distributions /tmp is a tmpfs sized at half of RAM, so spilling there writes the copy into RAM and, on an input larger than that, exhausts memory. The default scratch location is therefore the directory holding out_dir, and the space is verified before the first line is read.

source
MarketTickStreamer.RawSink — Type
RawSink

Append-only NDJSON writer with size-based file rolling. Create with open_raw_sink; feed via write_batch!; always close_sink! (final flush) on shutdown.

source
MarketTickStreamer._safesave — Method
_safesave(write_fn, path) -> String

Write a file through write_fn(tmp_path) so that path always holds the newest complete result and nothing already there is lost.

The content goes to <base>.partial<ext> in the same directory first (the extension is kept last because writers such as FileIO.save infer the format from it). If path already exists it is then preserved as the first free <base>_#N<ext>, N from 1 — a hard link where the filesystem allows one, a copy otherwise — and finally the partial file is renamed onto path. The rename replaces atomically on one filesystem, so at every instant path is either the previous complete file or the new complete one, never absent and never half-written. Backups are numbered in order of displacement: _#1 is the oldest.

If write_fn throws, the partial file is removed, path is left untouched and the exception propagates.

These are the semantics of DrWatson's safesave (newest data canonical, prior results kept as numbered backups) without the dependency.

MarketTickStreamer.compact_raw — Method
compact_raw(raw_paths, out_dir; format = :csv, dedup = true,
            mem_fraction = 0.5, tz = tz"America/New_York",
            max_live_heap_mb = nothing, scratch_dir = nothing,
            footprint_factor = 4.0, spill_headroom = SPILL_HEADROOM,
            max_open_spill_files = 256, compression = :none) -> Vector{String}

Compact raw NDJSON files into per-symbol, per-trading-day analysis files (out_dir/SYMBOL/YYYY-MM-DD.csv|.arrow), sorted by time_ns. An existing output is never destroyed: the new file takes the canonical name and the one it displaces is kept as a numbered backup YYYY-MM-DD_#N.csv|.arrow (safesave semantics, see _safesave). Returns the list of files written.

dedup = true drops exact duplicate prints (reconnection double-delivery, overlapping backfill/live captures, rows a vendor file repeats) via deduplicate_trades, logging the count for each symbol and day that had any. Small inputs are compacted in memory; when the estimated footprint exceeds mem_fraction of currently free RAM the input is instead streamed line-by-line into per-(symbol, day) spill files and each group is compacted independently — memory stays bounded by the largest single group. max_live_heap_mb additionally enforces the configured heap ceiling per group (check_live_heap).

The spill pass writes a verbatim copy of the input, so it needs scratch space of the input's own size. scratch_dir places it; the default is the directory containing out_dir, not tempdir() (see SPILL_HEADROOM). The free space is checked up front and compaction refuses to start without it (ResourceError).

footprint_factor is the estimated in-memory size of the parsed input per input byte, spill_headroom the scratch space required as a multiple of the input size, and max_open_spill_files the number of spill files held open at once: further groups are served by closing the least recently written file and reopening it in append mode, so the pass works within the process's file-descriptor limit however many symbol-days the input spans. The pipeline takes all of them from [limits].

Arrow output stores the symbol, exchange, conditions and tape columns dictionary-encoded, which costs nothing to read and takes a liquid US equity day from 65 to 44 bytes per print. compression (:zstd or :lz4, Arrow only; :none by default) compresses the record batches as well — 8 bytes per print with :zstd on the same day — at the price of memory-mapped reads: an uncompressed file is mapped and touched lazily, a compressed one is decompressed on load (64 ms against under 1 ms for that day). Uncompressed is the default.

Session orchestration

MarketTickStreamer.acquire_session_lock — Method
acquire_session_lock(data_dir) -> lock

One session per data tree: takes a PID-file lock at <data_dir>/.session.lock and throws if another live process already holds it (SessionError): two backfills interleaving on one raw directory would corrupt both. Stale locks from dead processes are broken automatically; release with close(lock).

source
MarketTickStreamer.finalize_session_meta — Method
finalize_session_meta(path, status; ticks, raw_files, ticks_processed = nothing, source = nothing) -> String

Rewrite the running sidecar with the final status ("completed", "interrupted" or "failed"), tick count, file list, and finish timestamp. The sidecar is a mutable status record: the safesave rule protects data products, not status metadata.

ticks counts the prints received and written to raw/. A session that also compacts passes ticks_processed, the prints it wrote to processed/; the two differ by the duplicates compaction dropped, and only a session that compacts has the second number to give.

source describes the vendor file an import session read — name, size, checksum, format and the reader's statistics — and is written as the sidecar's session.source table.

reconcile_sessions!(raw_dir) -> Int

Crash-only startup reconciliation: sidecars still marked running whose recorded process no longer exists on this host are relabeled aborted (their raw NDJSON remains valid to the last flushed line); zero-byte raw stubs are reported. Never deletes anything. Returns the number of sidecars relabeled.

MarketTickStreamer.run_backfill — Method
run_backfill(cfg::Config; provider = nothing) -> Vector{String}

Download historical trades for every configured symbol over [backfill.start_date, backfill.end_date] (the provider's trading days, session_days), persist them through the same raw-NDJSON + compaction path as live data (marked by recv_ns = 0), and return the processed file paths. The sidecar records both counts: session.ticks, the prints received, and session.ticks_processed, the prints stored after compaction removed duplicates — a vendor file can repeat rows.

With backfill.keep_raw = false (bulk source only) a day's raw parts are deleted once it is compacted: the checksum-verified vendor file under bulk/ is the day's record, and a rerun with resume = false rebuilds the day from it without the network. The NDJSON copy is about 21 times the vendor file on Binance trades, so this bounds the raw layer to one day.

Work is done one (symbol, day) at a time: its own raw part set, compacted as soon as that day finishes. Pages are flushed to disk as they arrive, so RAM stays bounded by one page and limits.max_live_heap_mb.

backfill.resume depends on that granularity. The skip test asks whether a day is already present under processed/, so a day must land there the moment it is complete and not before: a run killed after eight of twelve hours resumes at hour eight. Compacting only at the end would leave a killed run with raw data that resume cannot see, and the rerun would start from nothing.

An interrupted day is not compacted and is therefore downloaded again; its partial raw file is left on disk rather than deleted, and compaction deduplicates if it is ever folded in. Ctrl-C finalizes the provenance sidecar as interrupted and returns the days that did complete. Any other error finalizes it as failed and propagates; the days compacted before the error remain valid and a rerun resumes after them.

Logging is scoped to the call: the session runs under its own logger and the caller's global logger is untouched.

MarketTickStreamer.snapshots — Method
snapshots(fold!, ch, period_ns; on_snapshot, clock = :exchange) -> Int

Drain ch, folding every print into a consumer's state with fold!(t), and call on_snapshot(at_ns, n, final) at every boundary of a period clock and once when the channel closes. n is the number of prints folded before the call, at_ns the boundary time in nanoseconds, final whether the stream has ended. Returns the number of prints folded.

The clock is the exchange timestamp (clock = :exchange, time_ns) or the receipt timestamp (:recv, recv_ns); its boundaries are the multiples of period_ns, so a one-minute period snapshots at whole UTC minutes. The first boundary is the first multiple after the first print. A print at or beyond the next boundary triggers one call per boundary crossed, before it is folded, so a window without prints still yields its snapshot, with n unchanged. A late print, one behind the window already open, folds into that window: the boundary never retreats. The final call carries the last print's timestamp and final = true; an empty stream makes no call.

Snapshots are a function of the sequence alone, never of wall time, so a replay at any pace reproduces them exactly, and consumers fed by one tee produce aligned snapshots. This is the snapshot convention of the analysis interface: periodic state on the exchange clock, final state at close, each stamped with its boundary and its print count.

Example

rows = Tuple{Int64,Int,Float64}[]
n = snapshots(ch, 60 * 10^9; on_snapshot = (at, k, _) -> push!(rows, (at, k, value(acc)))) do t
    fit!(acc, t.size)
end

MarketTickStreamer.tee — Method
tee(src::Channel{Trade}, n; capacity = 10_000, lossy = falses(n),
    on_drop = nothing) -> Vector{Channel{Trade}}

Fan one tick stream out to n independent consumers (e.g. persistence plus real-time analysis taps). Outputs close when src closes.

Per-output overflow policy: a non-lossy output blocks the fan-out when full (backpressure: nothing is dropped; the setting for persistence). A lossy output drops the incoming tick instead when its buffer is full (use for analysis taps that must never stall the capture); drops are counted, reported via on_drop(output_index, n_dropped) when given, and warned on first occurrence.

A consumer that closes its output is dropped from the fan-out with a warning and the other outputs keep receiving, so an analysis tap that dies cannot end the persistence branch. If every output is closed the fan-out stops with an error record. A failure of the fan-out task itself is logged (errormonitor) rather than lost.

source
MarketTickStreamer.write_session_meta — Method
write_session_meta(cfg, sid; status, ticks, raw_files, started_utc,
                   finished_utc = nothing) -> String

Persist a provenance sidecar <raw_dir>/<sid>.meta.toml next to the session's raw files: session summary (id, status, pid, span, tick count, file list), provenance (git commit, dirty flag and whether the two could be read, Julia and package versions, hostname, the venue's timestamp unit, and the base name of a copy of the resolved Manifest.toml written alongside as <sid>.manifest.toml), a hardware fingerprint (CPU model and logical core count, total memory, Julia and BLAS thread counts, full versioninfo output), and the full effective configuration snapshot. Readers for vendor files, each holding one trading day of every symbol, and the import stage built on them.

MarketTickStreamer.fetch_itch50 — Method

MarketTickStreamer.itch50_trades — Method
itch50_trades(path, date; symbols = nothing, broken = :drop, each_page = nothing,
              page_rows = 100_000)
    -> (; trades, prints, messages, broken, unresolved, symbols, truncated)

The executions of one Nasdaq TotalView-ITCH 5.0 day file as Trade records, in file order. date is the session date (see itch50_date); timestamps are nanoseconds since that date's midnight in New York and are filed in ns since the epoch. path may be the gzip file as served or the raw bytes.

Prints are the Order Executed message (E, priced at the resting order's display price), the printable Order Executed With Price (C), the hidden Trade (P) and the Cross Trade with shares (Q); non-printable C and zero-share Q are not prints, by Nasdaq's own rule. Each print carries exchange = "Q", tape from the Stock Directory's market category, id = match number, and conditions = a kind token (displayed, improved, hidden, cross_open, cross_close, cross_halt, cross_intraday), the aggressor side (buy/sell) for E and C, and "I" when the size is below the symbol's round lot — the sale condition the SIP gives the same execution, so price_forming treats both alike.

symbols restricts the output (and the order map) to those symbols; nothing reads every symbol in the file. broken decides what a Broken Trade message does to the print it voids: :drop (default) omits it, :mark appends "broken" to its conditions, :keep leaves it as it was; the first two read the file twice, the voided ids being collected first.

each_page receives pages of page_rows prints as they are decoded and the returned trades is then empty; without it the prints are accumulated in trades. Every reader of the package returns this shape: trades, then prints, then its own statistics. messages counts every framed message, prints the emitted prints, broken the prints voided by a Broken Trade message (under :keep, the Broken Trade messages seen), unresolved the E messages whose order was unknown (a file cut before its Add Order), symbols the selected symbols found in the directory, and truncated whether the file ended inside a message, as a partial download does.

fetch_iex_hist(date, dir; feed = "TOPS", api_base = IEX_HIST_API,

Download the HIST capture of date for feed ("TOPS" or "DEEP", case-insensitive; the version is whatever IEX lists for that day) into dir/iex/, resuming an interrupted transfer, verify it against the CRC-32C the file host announces (x-goog-hash), and return its path. nothing when IEX lists no files for the date, a VendorError naming the feeds listed when the feed is not among them. A file already present is reused when its size matches the index entry and its CRC-32C the host's, and fetched again otherwise; a fresh download that fails the CRC-32C check is deleted and the call throws an IntegrityError.

MarketTickStreamer.iex_hist_trades — Method
iex_hist_trades(path; symbols = nothing, broken = :drop, tape = "", each_page = nothing,
                page_rows = 100_000)
    -> (; trades, prints, feed, packets, segments, messages, broken, gaps, duplicates,
          truncated)

The Trade Reports of one IEX HIST capture (.pcap.gz as published, or the decompressed pcap/pcapng) as Trade records, in capture order. The feed is read off the IEX-TP protocol id (TOPS 1.5, TOPS 1.6 or DEEP 1.0, whose Trade Report is one and the same message), not from the file name. Timestamps are the matching engine's, nanoseconds since the epoch; the capture clock is not read.

Each print carries exchange = "V" (IEX's market-centre code on the consolidated tape), id = IEX trade id (unique within the day), tape as given (a string for every print, or a Dict from symbol to tape; IEX does not publish the listing venue), and conditions = the set sale-condition flags as the letters IEX itself uses, which are the tape's: F intermarket sweep, T extended hours, I odd lot, 8 trade-through exempt, X single-price cross. A print with no flag has no condition.

symbols restricts the output; nothing keeps every symbol. broken decides what a Trade Break does to the print it voids: :drop (default) omits it, :mark appends "broken", :keep leaves it; the first two read the file twice. each_page and page_rows stream the prints as in itch50_trades. The statistics count captured packets, IEX-TP segments with messages, message blocks, emitted prints, voided prints (Trade Breaks seen, under :keep), sequence gaps and duplicate segments, and whether the capture ended inside a record.

MarketTickStreamer.run_import — Method
run_import(cfg, path; format, date = nothing, symbols = cfg.symbols, broken = :drop,
           tape = "", keep_raw = true, replace = false) -> Vector{String}

Import one vendor day file into the processed tree, as one session: the file's prints stream through a raw NDJSON part set (prefix import_<format>_<timestamp>), the day is compacted per symbol on the configured provider's calendar, and the sidecar records the file (name, size, SHA-256, format) and the reader's statistics under session.source, beside the usual provenance. Returns the processed files written.

format is :itch50 (itch50_trades) or :iex (iex_hist_trades). For either format date is the session date, read from the file name (itch50_date, iex_hist_date) when not given; ITCH timestamps count from midnight and are dated by it. symbols defaults to the configured basket; nothing imports every symbol in the file. broken and tape pass to the reader. With keep_raw = false the day's raw parts are deleted once the day is under processed/, the checksummed vendor file being the record, as backfill.keep_raw does for a bulk day.

A file that ends inside a message, as a partial download does, is imported to that point and logged as incomplete; the sidecar's source.truncated says so. The configured provider contributes its calendar and timestamp unit only; "alpaca" is the host for both US-equity formats.

The processed tree is keyed by symbol and day with no source dimension, so an imported day is filed where a capture of that day would be. A source therefore gets a data tree of its own, and the import refuses to write a (symbol, day) that already exists in processed/ unless replace = true, which displaces the existing files into safesave backups.

monitor_raw(dir; session = nothing, refresh_s = 2.0, top_symbols = 10,
            rate_window_s = 300.0, from_start = false,
            iterations = nothing, io = stdout) -> MonitorState

Attach a live in-terminal dashboard to the session whose raw NDJSON files live under dir (most recently active session unless session gives an id prefix).
