PROJECT CONTEXT: ALPACA MARKET DATA STREAMER IMPLEMENTATION IN JULIA

This document provides high-level architectural context and specific implementation details for a Julia-based market data ingestion system using the Alpaca Markets API.

ARCHITECTURAL OVERVIEW
The system is designed as a multi-tasked asynchronous application. It performs three primary functions: market state verification, real-time data streaming, and batched persistence. The choice of Julia leverages its native support for green threads (Tasks) and efficient I/O handling, allowing the system to handle high-frequency tick data without blocking the REPL or the file system.

AUTHENTICATION AND ENVIRONMENT
Credentials are managed via a .env file located in the script's root directory. The script uses the DotEnv.jl package to load 'ALPACA_API_KEY_ID' and 'ALPACA_SECRET_KEY'.

REST Authentication: Used for the Market Clock API. Credentials are passed in the HTTP headers as 'APCA-API-KEY-ID' and 'APCA-API-SECRET-KEY'.

WebSocket Authentication: Upon connection, the client must send a JSON payload with the 'auth' action containing the keys. The stream remains in a "pending" state until a 'success' message with 'authenticated' is received.

MARKET STATUS VERIFICATION
Before initiating a WebSocket connection, the script queries the Alpaca REST endpoint '/v2/clock'. This returns a JSON object indicating 'is_open' (boolean). The implementation logic checks this value first. If the markets are closed, the script outputs the next opening time and terminates to prevent unnecessary resource consumption or API errors.

WEBSOCKET FLOW AND PROTOCOL
The system connects to 'wss://stream.data.alpaca.markets/v2/sip' (for Pro/Paid accounts) or the 'iex' suffix (for Free accounts).

Message Framing: Alpaca sends data in JSON arrays, even if only one message is present. The script parses these into a 'Vector{Any}' and iterates through them.

Control Flow:

Establish Connection.

Send 'auth' message.

Wait for 'authenticated' success message.

Send 'subscribe' message for specific symbols (e.g., AAPL, MSFT).

Enter a continuous listening loop.

Message Types: The script filters for the 'T' field. 't' represents a Trade (Tick). Other types like 'q' (Quote) or 'b' (Bar) are available but currently filtered for REPL clarity.

CONCURRENCY AND DATA INTEGRITY
To prevent data loss and ensure a responsive REPL, the script uses a Producer-Consumer pattern implemented via Julia's '@async' macro.

The Producer: The WebSocket listener task. It pushes raw JSON strings into a shared 'data_buffer'.

The Consumer: The File Writer task. It periodically drains the buffer.

Thread Safety: Because Julia's scheduler can move tasks between threads (if started with multiple threads), a 'ReentrantLock' is used to wrap all interactions with the 'data_buffer'. This ensures that the writer doesn't attempt to clear the buffer while the listener is in the middle of a push.

BATCHED PERSISTENCE STRATEGY
Rather than writing to disk on every tick (which is I/O intensive), the script implements a "timed batch" approach. Every 60 seconds, the file writer task:

Acquires the lock.

Copies the buffer contents.

Clears the buffer.

Releases the lock.

Appends the copied data to 'market_data_output/alpaca_market_data.jsonl'.
The .jsonl (JSON Lines) format is chosen because it is natively compatible with big-data tools and allows for simple line-by-line recovery if the process is interrupted.

FULL IMPLEMENTATION CODE

using HTTP
using JSON3
using WebSockets
using Dates
using TimeZones
using DotEnv
using Printf

Path Setup
const SCRIPT_DIR = @DIR
const ENV_FILE_PATH = joinpath(SCRIPT_DIR, ".env")
const OUTPUT_DIR = joinpath(SCRIPT_DIR, "market_data_output")
const OUTPUT_FILENAME_PATH = joinpath(OUTPUT_DIR, "alpaca_market_data.jsonl")

Load Configuration
if isfile(ENV_FILE_PATH)
DotEnv.config(path=ENV_FILE_PATH)
end

const API_KEY = get(ENV, "ALPACA_API_KEY_ID", "")
const SECRET_KEY = get(ENV, "ALPACA_SECRET_KEY", "")
const API_BASE_URL = get(ENV, "ALPACA_API_URL", "https://api.alpaca.markets")
const WS_URL = "wss://stream.data.alpaca.markets/v2/sip"

Parameters
const SYMBOLS = ["AAPL", "MSFT", "GOOG"]
const WRITE_INTERVAL = 60
const MARKET_TZ = tz"America/New_York"

Shared State
const data_buffer = Vector{String}()
const buffer_lock = ReentrantLock()
const shutdown_flag = Ref(false)

function get_market_status()
headers = ["APCA-API-KEY-ID" => API_KEY, "APCA-API-SECRET-KEY" => SECRET_KEY]
url = "$API_BASE_URL/v2/clock"
resp = HTTP.get(url, headers)
return JSON3.read(resp.body)
end

function write_to_disk()
!isdir(OUTPUT_DIR) && mkpath(OUTPUT_DIR)
lock(buffer_lock) do
if !isempty(data_buffer)
open(OUTPUT_FILENAME_PATH, "a") do io
for entry in data_buffer
println(io, entry)
end
empty!(data_buffer)
end
end
end
end

function start_writer()
while !shutdown_flag[]
sleep(WRITE_INTERVAL)
!shutdown_flag[] && write_to_disk()
end
write_to_disk() # Final flush
end

function start_streamer()
WebSockets.open(WS_URL) do ws
# Step 1: Auth
auth_payload = JSON3.write(Dict("action" => "auth", "key" => API_KEY, "secret" => SECRET_KEY))
WebSockets.send(ws, auth_payload)

    while !shutdown_flag[] && WebSockets.isopen(ws)
        raw_data = WebSockets.receive(ws)
        raw_data === nothing && break
        
        msg_packet = JSON3.read(String(raw_data), Vector{Any})

        for msg in msg_packet
            type = get(msg, "T", "")
            
            if type == "success" && msg["msg"] == "authenticated"
                sub_payload = JSON3.write(Dict("action" => "subscribe", "trades" => SYMBOLS))
                WebSockets.send(ws, sub_payload)
            elseif type == "t" # Trade logic
                @printf("[TICK] %-5s | Price: %-8.2f | Size: %-5d | Time: %s\n", 
                        msg["S"], msg["p"], msg["s"], msg["t"])
                lock(buffer_lock) do
                    push!(data_buffer, JSON3.write(msg))
                end
            elseif type == "error"
                @error "Alpaca Error: " msg["msg"]
            end
        end
    end
end
end

function main()
println("System Initializing...")
try
status = get_market_status()
if !status.is_open
println("Market is currently closed. Operations suspended.")
return
end

    println("Market Open. Starting Tasks...")
    writer = @async start_writer()
    streamer = @async start_streamer()

    wait(streamer)
catch e
    if e isa InterruptException
        println("Shutdown initiated by user.")
        shutdown_flag[] = true
    else
        @error "Runtime Error: $e"
        shutdown_flag[] = true
    end
end
end

if abspath(PROGRAM_FILE) == @FILE
main()
end

OPERATIONAL NOTES

Ensure Julia has the following packages: HTTP, JSON3, WebSockets, Dates, TimeZones, DotEnv.

The script handles UTC-to-Local conversion for logging but displays the Alpaca-native RFC3339 timestamps in the REPL for raw verification.

To terminate, use Ctrl+C; the script will catch the signal, flip the shutdown_flag, and allow the file writer one final flush to ensure no data is lost from the buffer.
